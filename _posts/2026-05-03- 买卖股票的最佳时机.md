## 题目
- **难度**：简单  
- **题号**：121  
- **链接**：[LeetCode 121. 买卖股票的最佳时机](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)

## 题目描述
给定一个数组 `prices`，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0`。


## 核心思路1
**解法一**
维护两个变量：
1. **到今天为止的最低买入价**（`min` 变量记录遍历过程中看到的最低价格）。这个值永远是你如果在今天之前买入能拿到的最优成本。
2. **全局最大利润**（`profit`）。每天计算如果以当天价格卖出能获得的利润（`prices[i] - min`），并更新 `profit` 为最大值。

遍历一次即可得到答案。

## 关键代码

<!-- prettier-ignore -->
```python
def maxProfit(prices) -> int:
    # 定义一个最小价格
    min_price = prices[0]
    # 利润
    profit = 0
    for i in range(1, len(prices)):
        profit = max(profit, prices[i] - min_price)
        #下面这个可以换成min函数的比较
        if prices[i] < min_price:
            min_price = prices[i]
    return profit

```
## 核心思路2

**解法二：用数组记录状态**
min1[i]：记录前 i 天的最低股价。

dp[i]：记录第 i 天卖出的利润 = 当天价格 − 前 i-1 天的最低股价。

递推逻辑：
每天更新当日利润 dp[i]，并将当天价格纳入历史最低价 min1[i] = min(min1[i-1], prices[i])。
最后在 dp[1:] 中取最大值（与 0 比较）


```python
def maxProfit1( prices ) -> int:
    #定义一个最小价格
    min1 =[0]*len(prices)
    #每一个位置存储的是此天的利润
    dp= [0]*len(prices)

    min1[0] = prices[0]

    for i in range(1,len(prices)):
        #每次遍历i得到i-1天的最低价
        dp[i] = prices[i] - min1[i-1]
        #更新最小值
        min1[i] = min(min1[i-1],prices[i])
    return max(0,max(dp[1:]))
```
