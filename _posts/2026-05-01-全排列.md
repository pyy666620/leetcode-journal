## 关键代码1： 数组法

## 核心思路
创建三个数组 

第一个：维护一个属性：当前的值是否存过

第二个：保存最终结果

第三个：存储当前序列结果，

最重要的是回溯思想，递归调用，更改元素，递归满足条件则退出，递归之后再次更改元素值（保持原来的值）


<!-- prettier-ignore -->
```python
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        num1 = [False] * len(nums)
        num2 = []
        result = []

        def select2():
            if len(num2) == len(nums):
                result.append(num2[:])
                return
            for i in range(len(nums)):
                if num1[i]:
                    continue
                #如果对应下标为False
                num2.append(nums[i])
                num1[i] = True

                select2()

                num2.pop()
                num1[i] = False
        select2()
        return result
```
## 关键代码2： 原地回溯法

## 核心思路

知道怎么求 n−1 的全排列，就可以通过固定一个元素 + 拼接，求出 n 的全排列

在交换法的当前层（start），目的就是固定第 start 个位置的值。

<!-- prettier-ignore -->
```python
def permute(nums):
    #创建结果数组
    result = []
    def back(start):
        if start == len(nums):
            result.append(nums[:])
            return
        for i in range(start,len(nums)):
            if start != i:
                nums[start],nums[i] = nums[i],nums[start]
            back(start + 1)
            if start != i:
                nums[start], nums[i] = nums[i], nums[start]
    back(0)
    return result

print(permute([1,2,3]))
```
