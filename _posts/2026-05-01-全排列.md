## 题目
- **难度**：中等
- **题号**：46
- **链接**：[LeetCode 46. 全排列](https://leetcode.com/problems/permutations/)

## 核心思路
创建三个数组 

第一个：维护一个属性：当前的值是否存过

第二个：保存最终结果

第三个：存储当前序列结果，

最重要的是回溯思想，递归调用，更改元素，递归满足条件则退出，递归之后再次更改元素值（保持原来的值）

```python
class Solution:
    def permute(self, nums: List[int]) -> List[List[int]]:
        num1 = [False] * len(nums)
        num2 = []
        result = []

        def select2():
            if len(num2) == len(nums):
                result.append(num2[:])
                return
            for i in range(len(nums)):
                if num1[i]:
                    continue
                #如果对应下标为False
                num2.append(nums[i])
                num1[i] = True

                select2()

                num2.pop()
                num1[i] = False
        select2()
        return result
```
