## 题目
- **难度**：简单
- **链接**：[LeetCode 70. 爬楼梯](https://leetcode.com/problems/climbing-stairs/)

## 核心思路
用带备忘录的递归（自顶向下），爬到第 `i` 级的方法数等于爬到 `i-1` 与 `i-2` 的方法数之和
最后一步跨 1 级：说明你在到达第 i 阶之前，一定站在第 i-1 阶。
到达第 i-1 阶有 dp[i-1] 种方法，每一种方法后面接一个“跨 1 级”，就得到一种到达第 i 阶的方法。
这类方法共有 dp[i-1] 种。

最后一步跨 2 级：说明你在到达第 i 阶之前，一定站在第 i-2 阶。
到达第 i-2 阶有 dp[i-2] 种方法，每一种方法后面接一个“跨 2 级”，就得到另一种到达第 i 阶的方法。
这类方法共有 dp[i-2] 种。

任何到达第 i 阶的完整路径，最后一步要么是 1 级，要么是 2 级，不可能同时属于两者。

-注意:用数组 `memo` 存中间结果避免重复计算。

```python
class Solution:
    def climbStairs(self, n: int) -> int:
        # 数组长度 n+1 是因为要用索引 n 来存储最终答案
        memo = [0] * (n + 1)
        return self.helper(n, memo)
    def helper(self, i: int, memo: list[int]) -> int:
        # 递归基
        if i == 1:
            return 1
        if i == 2:
            return 2
        if memo[i] == 0:
            memo[i] = self.helper(i - 1, memo) + self.helper(i - 2, memo)
        return memo[i]
```
