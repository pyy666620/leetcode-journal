## 一、移除元素（LeetCode 27）

### 题目
- **难度**：简单
- **链接**：[27. 移除元素](https://leetcode.com/problems/remove-element/)

### 核心思路
原地移除所有等于 `val` 的元素，返回剩余元素数量。  
使用**快慢指针**：
- 慢指针 `x` 指向下一个保留元素应放的位置（也等于当前已保留的个数）。
- 快指针 `y` 遍历数组，遇到 `nums[y] != val` 时，将其复制到 `nums[x]`，然后 `x++`。
- 遍历结束，`x` 就是不等于 `val` 的元素个数，且数组前 `x` 个位置是有效元素。

### 代码
<!-- prettier-ignore -->
```python
def removeDuplicates(nums) -> int:
    #快慢指针
    x = 1
    for i in range(len(nums)-1):
        #读取后一个元素，不等于前一个元素，直接赋值索引为1，依次
        if nums[i+1] != nums[i]:
            nums[x] = nums[i+1]
            x += 1
    print(nums)
    return x

```
