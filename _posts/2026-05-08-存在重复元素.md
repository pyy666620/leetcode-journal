## 题目
- **难度**：简单  
- **题号**：219  
- **链接**：[LeetCode 219. 存在重复元素 II](https://leetcode.com/problems/contains-duplicate-ii/)

## 题目描述
给定一个整数数组 `nums` 和一个整数 `k`，判断是否存在两个不同的索引 `i` 和 `j`，满足 `nums[i] == nums[j]` 且 `abs(i - j) <= k`。存在返回 `true`，否则返回 `false`。

## 核心思路 : 维护一个大小不超过 k 的滑动窗口（集合）来检测重复



- 使用集合 `arr` 存储当前窗口内的元素，窗口定义为：**以当前索引 i 为右端点，最多向前延伸 k 个位置**（即索引范围 `[i-k, i-1]` 内的所有元素）。
- 遍历数组时，先检查 `num` 是否在 `arr` 中，如果存在，说明在距离 ≤ k 的范围内出现重复，直接返回 `true`。
- 如果不存在，将当前元素加入 `arr`。
- 当窗口长度超过 `k` 时（即 `len(arr) > k`），窗口左边界必须收缩，从集合中删除最左端元素 `nums[i-k]`。由于 i 从 0 开始遍历，`i-k` 正好是需要移出的元素索引。
- 遍历结束未返回，则返回 `false`。

**为什么集合大小会超过 k？**  
加入当前元素后，窗口实际包含从 `i-k` 到 `i` 共 `k+1` 个元素（假设都不同），但题目要求只需比较距离 ≤ k，所以窗口只需要保留最近 `k` 个元素。因此当长度超过 k 时，及时删除最旧元素，保证窗口大小始终 ≤ k。

## 关键代码

<!-- prettier-ignore -->
```python
class Solution:
    def containsNearbyDuplicate(self, nums: List[int], k: int) -> bool:
        arr = set()
        for i, num in enumerate(nums):
            if num in arr:
                return True
            arr.add(num)
            if len(arr) > k:
                arr.remove(nums[i - k])
        return False
```
