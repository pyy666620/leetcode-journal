## 题目
- **难度**：简单
- **链接**：[LeetCode 70. 爬楼梯](https://leetcode.com/problems/climbing-stairs/)

## 核心思路
定义一个数组,长度为n+1(因为要得到索引为n的数组值

排除特殊情况:一个台阶两个台阶 即为1和2,如果比两个多,循环遍历,后一个元素的值=前两个之和,最终得到索引为n的值

## 关键代码

<!-- prettier-ignore -->
```python
def climbStairs( n: int) -> int:
    # 数组长度 n+1 是因为要用索引 n 来存储最终答案
    memo = [0] * (n + 1)
    if n == 1:
        return 1
    if n == 2:
        return 2
    memo[1] = 1
    memo[2] = 2

    for i in range(3,n+1):
        memo[i] = memo[i-1] + memo[i-2]
    return memo[n]

print(climbStairs(5))
```
