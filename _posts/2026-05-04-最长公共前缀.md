## 题目

- **题号**：14  
- **链接**：[LeetCode 14. 最长公共前缀](https://leetcode.com/problems/longest-common-prefix/)


## 思路一：横向扫描
先拿第一个字符串当前缀
然后一个一个地和后面的字符串逐字符比较
遇到不同就缩短前缀，直到比完所有字符串
### 代码
<!-- prettier-ignore -->
```python
#迭代版本
def longestCommonPrefix(strs: List[str]) -> str:
    #定义第一个元素为公共前缀
    first = strs[0]
    if len(first) == 0:
        return  ""
    #遍历得到当前元素
    for i in range(1,len(strs)):
        # 存放当前位置的公共索引
        end = ""
        now_str = strs[i]
        if len(now_str) == 0:
            return ""
        #得到最小长度，防止数组越界
        min_len = min(len(first),len(now_str))
        for j in range(min_len):
            if now_str[j] == first[j]:
                end += now_str[j]
            else:
                break
        first = end
    return first
```
## 思路二：递归
#递归版本

多个字符串的 LCP，转化成反复求两个字符串的 LCP

#得到最终结果

### 代码
<!-- prettier-ignore -->
```python
def longestCommonPrefix1(strs: List[str]) -> str:
    return left_right(strs,0,len(strs) - 1)

#递归函数：不断调用自己
def left_right(strs,left,right):
    #递归终止条件
    if left == right:
        return strs[0]
    #如果不满足条件，继续递归
    new_left = left_right(strs,left,right-1)
    new_right = strs[right]
    result = two(new_left,new_right)
    return result
#得到两个元素的最大公共前缀
def two(left,right):
    result = ""
    #得到两个元素的的最小长度：防止数组越界
    min_len = min(len(left),len(right))
    for i in range(min_len):
        if left[i] == right[i]:
            result = result + left[i]
        #如果不相等直接返回
        else:
            return result
    return result
```
