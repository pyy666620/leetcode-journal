## 题目
- **难度**：简单
- **题号**：27
- **链接**：[LeetCode 27. 移除元素](https://leetcode.com/problems/remove-element/)

## 核心思路
使用快慢双指针：  
- 慢指针 `x` 指向下一个要覆盖的位置。  
- 快指针 `y` 遍历整个数组。  
- 当 `nums[y]` 不等于目标值 `n` 时，将其复制到 `nums[x]`，然后 `x` 后移一位。  

## 关键代码

<!-- prettier-ignore -->
```python
def remove(nums, n):
    # 慢指针，指向下一个不应被移除的元素应放置的位置
    x = 0
    for y in range(len(nums)):
        if n != nums[y]:
            nums[x] = nums[y]
            x += 1
    return x
```
