## 题目描述
在数组中找到和为 `target` 的两个整数，返回它们的下标。每种输入只有一个答案，且同一元素不能使用两次。

## 核心思路
遍历一次，变遍历变存入哈希表 ： 原因如下：

1.如果直接存入再判断，重复值该如何写？

2.先转成字典再遍历时，一旦出现 num = target - num（即 target = 2 * num）的情况，字典中配对值的索引可能就是你当前正在看的这个元素本身。

故先遍历当前值，在判断相减后的值在不在字典中，如果不在存入当前值

## 关键代码

```python
def twoSum(nums , target: int) :
    ls = len(nums)
    dic = {}
    for i in range(ls):
        data = nums[i]
        value = dic.get(target-data)
        if value is not None:
            return [i,value]
        else:
            dic[nums[i]] = i
```
